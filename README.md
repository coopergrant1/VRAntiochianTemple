# Virtual Cultural Heritage VR Project

## Overview
This project uses **3D LiDAR scans** and **photogrammetry** to create immersive **virtual reality (VR) experiences** of world heritage sites. The goal is to preserve, explore, and study culturally significant locations through interactive virtual environments, while making these resources accessible to a broad academic audience.

The project builds on an existing **VR development program embedded in Study Abroad programs in Greece and Italy**, extending prior work that requires continued development and integration.

## Team Focus
- Create high-fidelity VR reconstructions of archaeological sites and artifacts  
- Develop an **interactive online library** to house VR collections  
- Enable **Georgia Tech students** across disciplines to engage with computational media for cultural heritage  
- Support the creation of **virtual museums** for geographically isolated or inaccessible sites  

## Key Research Challenges

### 1. Transparency of Evidence
Reconstructions are overlaid directly on photogrammetric and LiDAR data to clearly communicate how much evidence supports each hypothesis. This ensures that interpretations are presented honestly and academically.

### 2. Variability and Uncertainty
Multiple reconstructions are used to represent uncertainty, highlighting a **range of plausible interpretations** rather than a single definitive model.

## Methods and Technologies
- **Digital Documentation**

- **Modeling**
  - Digital modeling
  - Parametric modeling
- **Development**

## Project Goals

- Provide immersive educational tools for students and researchers
